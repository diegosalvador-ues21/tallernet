# H-28 — MySQL Workbench consultaba otro servidor (entorno)
Severidad: Media (entorno)     Tipo: Configuración
Detectado por: relevamiento de conexiones activas (`lsof`)    Fecha: 2026-11-07
## Descripción
La conexión «MySQL@Mac» de Workbench apunta a 127.0.0.1:**3306** (MySQL Enterprise 26.7 nativo). La base de TALLERNET corre en Docker en 127.0.0.1:**3307**. Un alta exitosa nunca aparecería en Workbench.
## Corrección
Se documentó en `PUESTA_EN_MARCHA.md` una conexión «TALLERNET (Docker 3307)». La opción 6 › 1 «Probar conexión» del programa muestra el servidor real.
